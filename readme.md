# Prompt Quizzer – A Quiz Game

## Project Description
Prompt Quizzer is a simple JavaScript quiz game that runs in the browser console. It asks predefined questions and checks the user's answers.

## Features
- Stores questions and answers in an array.
- Uses a for loop to display questions one by one.
- Takes user input using prompt().
- Checks answers using toLowerCase() and trim().
- Displays correct and wrong answer feedback using alert().
- Tracks the score.
- Displays the final score after all questions.

## Technologies Used
- JavaScript
- HTML
- Visual Studio Code
- Google Chrome

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open index.html using Live Server.
3. Open the browser Developer Tools by pressing F12.
4. Go to the Console tab.
5. Run the quiz using runQuiz().
6. Answer all the questions and check your final score.
